# AFML Quant Platform

Book-first quantitative-research agent harness based on the user-supplied edition of *Advances in Financial Machine Learning* by Marcos López de Prado.

## Working roots

- `system/`: readable C++20 production interfaces and tests; Python is permitted for book-faithful reference implementations and independent numerical oracles.
- `instructions/`: preserved requirements, source-order chapter tasks, provenance, cross-checks, review evidence and engineering templates.

## Publication boundary

This repository is public. The original EPUB, full Word transcription, extracted book text, equation images and full-source task packets must remain local and must not be committed. A lawful local copy is required for source-dependent checks. Public task descriptions are engineering interpretations, not replacements for the book.

## Status

Repository initialization only. The prepared local harness is being transferred and checked. No live-trading system, exhaustive mathematical approval, zero-delay guarantee or deployment is claimed. Subsequent status and test-evidence files will distinguish executed checks from remaining work.
