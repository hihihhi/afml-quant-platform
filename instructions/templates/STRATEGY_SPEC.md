# Strategy specification — draft contract template

Record stable identity, source sections, explicit economic hypothesis and falsifiable
failure criteria. Separate signal definition, prediction, bet sizing, allocation and
execution assumptions rather than hiding them in a single return calculation.

Specify input features and their availability, decision schedule, state, parameters,
market/universe/sector membership as known at the time, admissible actions, costs,
limits and unsupported conditions. Keep all researched parameter choices in a trial
ledger, not only the best backtest. A non-ML strategy still needs validation.

Record labels and sample weights when applicable, fitted-state scope, training-only
selection, source-described split/purge/embargo conventions, historical versus
counterfactual validation interpretation, alternative paths and statistics. Link the
source rather than substituting generic walk-forward testing for the book's methods.

Provide exact small-case fixtures, independent reference results, C++ equivalence,
precision contract, adverse/missing/corrected-data cases, deterministic replay and
state-transition tests. Document hypothetical execution assumptions; this template
cannot send orders and does not confer approval to trade or deploy.

Conclude with independent review evidence, unresolved risks, version identities,
measured performance, and explicit approved/blocked status.
